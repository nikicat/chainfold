<task type="auto">
  <name>Task 2: Erc20Source with filter pushdown and alloy re-exports</name>
  <files>src/modules/erc20.rs</files>
  <action>
Add Erc20Source to `src/modules/erc20.rs`:

1. **Error type:**
   ```rust
   #[derive(Debug, thiserror::Error)]
   pub enum Erc20SourceError {
       #[error("RPC error: {0}")]
       Rpc(#[from] alloy::transports::TransportError),
       #[error("parse error: {0}")]
       Parse(String),
   }
   ```

2. **Erc20Source struct** — generic over `P: Provider`:
   ```rust
   pub struct Erc20Source<P: Provider> {
       provider: P,
       token: [u8; 20],
       filter: Erc20Filter,
       chunk_size: u64,
       from_block: u64,
   }
   ```
   With constructor:
   ```rust
   impl<P: Provider> Erc20Source<P> {
       pub fn new(provider: P, token: [u8; 20], filter: Erc20Filter, chunk_size: u64, from_block: u64) -> Self { ... }
   }
   ```

3. **Helper function** `fn address_to_topic(addr: &[u8; 20]) -> FixedBytes<32>` — left-pad 20-byte address to 32-byte topic (12 zero bytes + 20 address bytes).

4. **Internal method** `async fn fetch_logs_in_range(&self, from: u64, to: u64) -> Result<Vec<Log>, Erc20SourceError>`:
   - For `AllTransfers`: single `Filter::new().address(token).event_signature(TRANSFER_TOPIC).from_block(from).to_block(to)`, call `provider.get_logs()`
   - For `Account(addr)`: two queries (topic1=addr for FROM, topic2=addr for TO), `tokio::join!` both, merge into `BTreeMap<(u64, u32), Log>` keyed by (block_number, log_index) for dedup, return sorted values

5. **Internal method** `fn parse_transfer_log(log: &Log) -> Option<(EvmCursor, Transfer)>`:
   - Extract from/to from topics[1]/topics[2] (bytes 12..32), amount from data (U256 big-endian -> u128)
   - Return EvmCursor + Transfer

6. **EventSource impl** for `Erc20Source<P>` where `P: Provider`:
   - `fetch_state`: return `Ok(Vec::new())` (no RPC state fetch for ERC20)
   - `fetch_blocks`:
     - Clamp from_height to self.from_block (skip blocks below floor)
     - Chunk the range by self.chunk_size (reuse existing pattern from example)
     - For each chunk, call `fetch_logs_in_range(cursor, chunk_end)`
     - Group logs by block_number into BTreeMap
     - For each block with events, fetch block header via `provider.get_block_by_number()` for real block_hash and parent_hash
     - Return Vec<Block<EvmCursor, Transfer>> in height order
   - `subscribe`: return empty stream (documented limitation, matching PoC behavior)

7. Ensure all public types have appropriate `Send + Sync` bounds satisfied. The `P: Provider` bound already implies `Send + Sync` from alloy's trait definition.

Note: The `TransportError` type path may need adjustment based on actual alloy 1.7 API. Check `alloy::transports::TransportError` or `alloy::transports::RpcError`. Use the correct path that compiles.
