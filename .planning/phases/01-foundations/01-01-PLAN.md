Create `src/cursor/btc.rs`:
- Same derive set as EvmCursor.

- Manual `PartialOrd` impl delegating to `Ord`.

- Test serde_json round-trip for all three cursor types

- Display impl: delegate to inner error.
- This is the generic error wrapper per locked decision — adapters wrap their own errors into this.

Create `src/event.rs`:
- `use crate::cursor::ChainCursor;`
- `#[derive(Debug, Clone)]`
- `pub struct Event<C: ChainCursor, E> { pub cursor: C, pub data: E, pub block_hash: Option<[u8; 32]> }`
- Generic parameter order: C first (more constrained), E second. Per research recommendation.
- No Serialize bound on E — events are opaque to the library in Phase 1.

Create `src/source.rs`:
- Use `#[async_trait::async_trait]` (per research: simpler for Phase 1, migrate to trait_variant in Phase 3).
- Define `EventSource` trait:
  ```rust
  #[async_trait::async_trait]
  pub trait EventSource: Send + Sync {
      type Cursor: ChainCursor;
      type Event: Send + 'static;
      type Error: std::error::Error + Send + Sync + 'static;

      async fn fetch_state(&self, at: &Self::Cursor) -> Result<Vec<u8>, Self::Error>;
      async fn fetch_events(
          &self,
          from: &Self::Cursor,
          to: &Self::Cursor,
      ) -> Result<Vec<Event<Self::Cursor, Self::Event>>, Self::Error>;
      async fn subscribe(
          &self,
          from: &Self::Cursor,
      ) -> Result<
          Box<dyn futures_core::Stream<Item = Result<Event<Self::Cursor, Self::Event>, Self::Error>> + Unpin + Send>,
          Self::Error,
      >;
  }
  ```
- Note: `subscribe` returns `Box<dyn Stream>` because `async_trait` doesn't support `impl Trait` in return position. This is the known tradeoff — acceptable for Phase 1.
- Add `futures-core` to `[dependencies]` in Cargo.toml for the Stream trait.

Update `src/lib.rs` to re-export: `pub use cursor::ChainCursor;`, `pub use event::Event;`, `pub use source::EventSource;`, `pub use error::SourceError;`
