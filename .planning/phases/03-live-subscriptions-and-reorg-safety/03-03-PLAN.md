**The `run()` method:**

```rust
/// Run the live event loop.
///
/// Subscribes to the EventSource, processes blocks in micro-batches,
/// handles disconnection with exponential backoff, and fills gaps after
/// reconnection. Reorgs are detected and handled transparently via
/// process_or_reorg.
///
/// Returns Ok(()) on graceful cancellation (CancellationToken triggered).
/// Returns Err on unrecoverable errors (storage failure, max retries exhausted).
///
/// Caller owns task lifecycle:
/// ```ignore
/// let token = CancellationToken::new();
/// let handle = tokio::spawn(engine.run(source, token.clone(), on_reorg, on_status));
/// // ... later ...
/// token.cancel();
/// handle.await??;
/// ```
pub async fn run<ES>(
    &mut self,
    source: ES,
    cancel: CancellationToken,
    mut on_reorg: impl FnMut(ReorgEvent),
    mut on_status: impl FnMut(EngineStatus),
) -> Result<(), EngineError>
where
    ES: EventSource<Cursor = SM::Cursor, Event = SM::Event>,
{
    let mut attempt: u32 = 0;

    loop {
        // Determine the height to subscribe from.
        // Use the stored canonical tip height + 1, or 0 if no tip.
        let subscribe_height = self.current_tip_height()
            .map_err(|e| EngineError::Storage(e))? + 1;

        // Attempt to subscribe.
        let stream = match source.subscribe(subscribe_height).await {
            Ok(s) => {
                if attempt > 0 {
                    on_status(EngineStatus::Reconnected);
                }
                attempt = 0;
                s
            }
            Err(e) => {
                if attempt >= self.config.max_retries {
                    return Err(EngineError::ReconnectExhausted(
                        attempt,
                        Box::new(e),
                    ));
                }
                on_status(EngineStatus::Reconnecting(attempt + 1));
                let delay = backoff_delay(&self.config, attempt);
                tokio::select! {
                    biased;
                    _ = cancel.cancelled() => return Ok(()),
                    _ = tokio::time::sleep(delay) => {}
                }
                attempt += 1;
                continue;
            }
        };

        // Micro-batch the stream with ready_chunks.
        let mut batched = stream.ready_chunks(self.config.batch_size);

        // Inner loop: drain batches until stream ends or cancellation.
        let stream_result = loop {
            tokio::select! {
                biased;
                _ = cancel.cancelled() => {
                    break Ok(true); // cancelled = true
                }
                batch = batched.next() => {
                    match batch {
                        None => {
                            // Stream ended cleanly.
                            break Ok(false); // cancelled = false (stream ended)
                        }
                        Some(results) => {
                            for result in results {
                                let block = result
                                    .map_err(|e| EngineError::Source(Box::new(e)))?;
                                self.process_or_reorg(&block, &mut on_reorg)?;
                            }
                        }
                    }
                }
            }
        };

        match stream_result {
            Ok(true) => return Ok(()),  // Graceful cancellation.
            Ok(false) => {
                // Stream ended — reconnect.
                on_status(EngineStatus::Disconnected);
                attempt = 0; // Reset attempt counter for the fresh reconnect cycle.
                // Continue the outer loop to re-subscribe.
            }
            Err(e) => return Err(e),    // Unrecoverable error.
        }
    }
}
```

**Helper: `current_tip_height`:**

```rust
/// Get the current canonical tip height, or 0 if no tip exists.
/// Returns the height as a value (not wrapped in Option) since callers
/// always need a numeric height for subscribe().
fn current_tip_height(&self) -> Result<u64, Box<dyn std::error::Error + Send + Sync>> {
    let tip_hash = self.storage.get_canonical_tip(&self.config.source_id)
        .map_err(|e| -> Box<dyn std::error::Error + Send + Sync> { Box::new(e) })?;
    match tip_hash {
        None => Ok(0),
        Some(hash) => {
            let height = self.storage.get_block_height(&hash)
                .map_err(|e| -> Box<dyn std::error::Error + Send + Sync> { Box::new(e) })?
                .unwrap_or(0);
            Ok(height)
        }
    }
}
```

**Helper: `backoff_delay`:**

```rust
/// Compute exponential backoff delay for reconnection attempts.
fn backoff_delay(config: &EngineConfig, attempt: u32) -> std::time::Duration {
    let base = config.initial_delay_ms;
    let max = config.max_delay_ms;
    // 2^attempt * base, capped at max. Saturating to avoid overflow.
    let shift = attempt.min(31);
    let ms = base.saturating_mul(1u64 << shift).min(max);
    std::time::Duration::from_millis(ms)
}
```

**Gap fill after reconnection:**

IMPORTANT: After reconnection, gap fill is needed between the stored tip and the subscription start. However, the subscription is called with `tip_height + 1`, so the stream starts from where we left off. The existing `process_block` deduplication handles any overlap.

If the subscription implementation starts from a LATER height than requested (e.g., some blocks were missed during disconnect), the gap is NOT automatically filled by the stream. In that case, we'd need a gap fill step. However, per CONTEXT.md, the gap fill is integrated via the stream itself and dedup: "After reconnection, reuse Phase 2's fetch_gap() code path to fill the gap."

For the clean implementation: after reconnecting, check if the first block's height from the stream is ahead of our tip height. If so, fetch gap blocks first. This is subtle and hard to implement without peeking at the first stream item.

PRACTICAL RESOLUTION: The simplest correct approach is to rely on `process_block` deduplication and the `subscribe(from_height)` contract. The EventSource implementation is responsible for returning blocks from `from_height` onwards. If there's a gap, it means the source doesn't have those blocks — there's nothing to fetch. The reconnection is sufficient.

However, for sources that CAN miss blocks (e.g., Ethereum WS that was down), the gap fill after reconnect is valuable. Implement it as an optional step: after successful reconnect, call `fetch_gap_blocks` from the stored tip to the live tip (which requires knowing the live tip — we can get the first block from the stream and check).

For simplicity in Phase 3: after reconnection, if the first block from the stream has height > stored_tip + 1, fetch the gap using `fetch_gap_blocks` before processing the stream. This requires peeking at the first block. Use a simple approach: process each block in the inner loop, but also check for gaps inline.

SIMPLEST: The `subscribe(from_height)` contract + `process_block` dedup is sufficient. The gap fill after reconnect is handled by the EventSource implementation returning blocks from `from_height`. If the source can't return old blocks, the gap must be filled by `fetch_blocks`. Add an inline gap check: before processing a block, if its height > stored_tip + 1, call fetch_gap_blocks.
