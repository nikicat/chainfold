  <behavior>
    - compute_filter_hash: same (address, topics) produces same hash; different inputs produce different hashes; null topics use 0xFF sentinel
    - record_scanned_range: new range persists; overlapping ranges merge ([100,200] + [150,250] -> [100,250]); adjacent ranges merge ([100,200] + [201,300] -> [100,300]); gap-of-1 does NOT merge ([100,200] + [202,300] stays separate); contained range is absorbed ([100,300] + [150,200] -> [100,300]); identical range is idempotent
    - get_scanned_ranges: returns sorted non-overlapping ranges for a filter_hash
    - compute_gaps: given requested [from,to] and scanned ranges, returns only uncovered sub-ranges; fully covered returns empty vec; no scanned ranges returns full range
    - insert_logs: logs are stored and can be retrieved by filter_hash and block range; INSERT OR IGNORE deduplicates by (filter_hash, block_number, log_index)
    - get_cached_logs: returns logs in a range ordered by (block_number, log_index); returns empty vec for uncached range
    - insert_block_header / get_block_header: round-trip stores and retrieves block header fields by height
  </behavior>

       - `pub struct LogCache { conn: Mutex<Connection> }` with methods:
         - `pub fn open(path: &str) -> Result<Self, StorageError>` — opens own connection, calls configure_connection, runs migrations (idempotent).
         - `pub fn open_in_memory() -> Result<Self, StorageError>` — for tests.
         - `pub fn record_scanned_range(&self, filter_hash: &[u8; 32], start: u64, end: u64) -> Result<(), StorageError>` — eager merge-on-write per RESEARCH.md Pattern 3. Use `unchecked_transaction()`. Query merge candidates where `start_block <= end + 1 AND end_block >= start - 1` (use saturating_sub for start-1).

         - `pub fn insert_logs(&self, filter_hash: &[u8; 32], logs: &[alloy::rpc::types::Log]) -> Result<(), StorageError>` — batch insert with INSERT OR IGNORE. Single transaction.
         - `pub fn get_cached_logs(&self, filter_hash: &[u8; 32], from_block: u64, to_block: u64) -> Result<Vec<alloy::rpc::types::Log>, StorageError>` — query by filter_hash and block range, reconstruct alloy Log objects. Order by (block_number, log_index).
         - `pub fn insert_block_header(&self, height: u64, hash: &[u8; 32], parent_hash: &[u8; 32], timestamp: u64) -> Result<(), StorageError>` — INSERT OR REPLACE.

       - `pub fn compute_gaps(requested: (u64, u64), scanned: &[(u64, u64)]) -> Vec<(u64, u64)>` — sweep algorithm per RESEARCH.md Pattern 4. Takes sorted non-overlapping scanned ranges.
