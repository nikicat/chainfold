Main recovery function:

```rust
/// Run the full block DAG recovery pipeline.
///
/// Sequence:
/// 1. Read canonical_tip from storage
/// 2. If tip exists: find nearest snapshot, load state, replay forward, fetch gap
/// 3. If no tip (cold start): fetch_state from source, then fetch_blocks for history
///
/// After recovery, Engine state is consistent with live_tip_height.
pub async fn recover<SM, S, ES, C>(
    engine: &mut Engine<SM, S, C>,
    source: &ES,
    live_tip_height: u64,
) -> Result<(), RecoveryError>
where
    SM: StateMachine,
    S: Storage,
    ES: EventSource<Cursor = SM::Cursor, Event = SM::Event>,
    C: Codec<Cursor = SM::Cursor, Event = SM::Event, State = SM::State>,
{
    let source_id = engine.source_id().to_string();

    // Step 1: Read canonical tip
    let tip_hash = engine.storage()
        .get_canonical_tip(&source_id)
        .map_err(|e| RecoveryError::Storage(Box::new(e)))?;

    let tip_height = match &tip_hash {
        Some(hash) => {
            engine.storage()
                .get_block_height(hash)
                .map_err(|e| RecoveryError::Storage(Box::new(e)))?
                .unwrap_or(0)
        }
        None => 0,
    };

    match tip_hash {
        Some(tip) => warm_recovery(engine, source, &source_id, tip, tip_height, live_tip_height).await,
        None => cold_start(engine, source, &source_id, live_tip_height).await,
    }
}
```

```rust
async fn warm_recovery<SM, S, ES, C>(
    engine: &mut Engine<SM, S, C>,
    source: &ES,
    source_id: &str,
    tip_hash: [u8; 32],
    tip_height: u64,
    live_tip_height: u64,
) -> Result<(), RecoveryError>
where ...
{
    // Step 2: Find nearest snapshot on canonical chain
    let snapshot_result = engine.storage()
        .find_nearest_snapshot(source_id, &tip_hash)
        .map_err(|e| RecoveryError::Storage(Box::new(e)))?;

    let replay_from_hash = match snapshot_result {
        Some((snap_hash, snap_payload)) => {
            // Decode and load snapshot state
            let state = engine.codec()
                .decode_state(&snap_payload)
                .ok_or(RecoveryError::DecodeState)?;
            engine.replace_state(state);
            snap_hash
        }
        None => {
            // No snapshot -- need fetch_state for initial state, then replay ALL blocks
            // Use a genesis cursor (implementation-defined; fetch_state at "beginning")
            // For recovery without any snapshot, we fetch initial state and replay everything.
            // This is the fallback path described in CONTEXT.md.
            cold_start_state(engine, source).await?;
            // Return a sentinel: we need to replay from genesis
            // Since there's no snapshot block to start from, we replay the entire chain
            // Use collect_canonical_chain from the first block's parent (which doesn't exist)
            // Actually: replay ALL blocks from genesis to tip.
            // We can get the genesis block by walking back from tip.
            // Simplest: collect the full chain by walking backward, then replay all.
            replay_full_chain(engine, source_id, tip_hash)?;
            // After replaying all stored blocks, fetch gap
            if tip_height < live_tip_height {
                fetch_gap_blocks(engine, source, tip_height + 1, live_tip_height).await?;
            }
            return Ok(());
        }
    };

    // Step 3: Collect canonical chain from snapshot block to tip (replay forward)
    if replay_from_hash != tip_hash {
        let chain = engine.storage()
            .collect_canonical_chain(&replay_from_hash, &tip_hash)
            .map_err(|e| RecoveryError::Storage(Box::new(e)))?;

        // Replay events for each block in forward order
        for block_hash in &chain {
            let stored_events = engine.storage()
                .load_block_events(block_hash)
                .map_err(|e| RecoveryError::Storage(Box::new(e)))?;

            let events = decode_stored_events::<SM, C>(engine.codec(), &stored_events);
            engine.replay_events(&events);
        }
    }

    // Step 4: Fetch gap blocks from source if behind live tip
    if tip_height < live_tip_height {
        fetch_gap_blocks(engine, source, tip_height + 1, live_tip_height).await?;
    }

    Ok(())
}
```

- "No valid snapshots — fetch initial state from source": this means if we have blocks but no usable snapshot, we need fetch_state. But the Engine is created with initial state by the caller before recovery runs.
- For cold start (no blocks at all): Engine already has initial state. Just fetch blocks.

1. Replaces it with a snapshot state (warm + snapshot)
2. Replaces it with fetch_state result (warm + no snapshot, or cold start) -- but this requires a genesis cursor
3. Keeps it and replays all blocks from genesis (warm + no snapshot where initial state matches genesis)

Actually the simplest: don't call fetch_state in recovery at all. The caller creates Engine with initial state. Recovery is about catching up storage state, not about initial state.

Let me revise: Recovery has these cases:
1. **Empty DB (cold start)**: Engine has initial state from constructor. Fetch all blocks from source. Process them through Engine.
2. **Warm with snapshot**: Load snapshot -> replay -> gap fetch.

```rust
pub async fn recover<SM, S, ES, C>(
    engine: &mut Engine<SM, S, C>,
    source: &ES,
    live_tip_height: u64,
) -> Result<(), RecoveryError>
where
    SM: StateMachine,
    S: Storage,
    ES: EventSource<Cursor = SM::Cursor, Event = SM::Event>,
    C: Codec<Cursor = SM::Cursor, Event = SM::Event, State = SM::State>,
{
    let source_id = engine.source_id().to_string();

    let tip_hash = engine.storage()
        .get_canonical_tip(&source_id)
        .map_err(|e| RecoveryError::Storage(Box::new(e)))?;

    match tip_hash {
        None => {
            // Cold start: no blocks in DB. Engine already has initial state.
            // Fetch all blocks from source.
            fetch_gap_blocks(engine, source, 0, live_tip_height).await?;
        }
        Some(tip) => {
            let tip_height = engine.storage()
                .get_block_height(&tip)
                .map_err(|e| RecoveryError::Storage(Box::new(e)))?
                .unwrap_or(0);

            // Try to find a snapshot
            let snapshot_result = engine.storage()
                .find_nearest_snapshot(&source_id, &tip)
                .map_err(|e| RecoveryError::Storage(Box::new(e)))?;

            match snapshot_result {
                Some((snap_hash, snap_payload)) => {
                    // Load snapshot state
                    let state = engine.codec()
                        .decode_state(&snap_payload)
                        .ok_or(RecoveryError::DecodeState)?;
                    engine.replace_state(state);

                    // Replay from snapshot to tip
                    if snap_hash != tip {
                        replay_chain(engine, &snap_hash, &tip)?;
                    }
                }
                None => {
                    // No snapshot: engine has initial state.
                    // Replay ALL blocks from genesis to tip.
                    replay_full_chain(engine, &source_id, tip)?;
                }
            }

            // Fetch gap if behind live tip
            if tip_height < live_tip_height {
                fetch_gap_blocks(engine, source, tip_height + 1, live_tip_height).await?;
            }
        }
    }

    Ok(())
}
```

```rust
/// Replay stored events for blocks on the canonical chain from from_hash to to_hash.
fn replay_chain<SM, S, C>(
    engine: &mut Engine<SM, S, C>,
    from_hash: &[u8; 32],
    to_hash: &[u8; 32],
) -> Result<(), RecoveryError>
where ...
{
    let chain = engine.storage()
        .collect_canonical_chain(from_hash, to_hash)
        .map_err(|e| RecoveryError::Storage(Box::new(e)))?;

    for block_hash in &chain {
        replay_block_events(engine, block_hash)?;
    }
    Ok(())
}

/// Replay all blocks from genesis to tip (no snapshot available).
/// Walks backward from tip to genesis, collects all block hashes, reverses, replays.

    engine: &mut Engine<SM, S, C>,
    source_id: &str,
    tip_hash: [u8; 32],
) -> Result<(), RecoveryError>
where ...
{
    // Walk backward from tip, collecting all hashes
    let mut chain: Vec<[u8; 32]> = Vec::new();
    let mut current = tip_hash;
    loop {
        chain.push(current);
        let height = engine.storage()
            .get_block_height(&current)
            .map_err(|e| RecoveryError::Storage(Box::new(e)))?;

        // Look up parent
        // We need parent_hash. But Storage trait doesn't have get_parent_hash.
        // We need to either add it or use a different approach.
        // Actually, we can use collect_canonical_chain with a sentinel.
        // OR: since this is "replay ALL blocks from genesis to tip",
        // and genesis is height 0, we can iterate by height using load_block_events.
        // But blocks are keyed by hash, not height.
        //
        // SIMPLEST: Add the walk-to-genesis logic here, or make collect_canonical_chain
        // work with a genesis sentinel.
        //
        // The cleanest: walk backward using Storage queries until parent is all-zeros.
        // We need a get_parent_hash method or the walk is in the Storage impl.
        //
        // Resolution: collect_canonical_chain already does backward walk.
        // For full chain replay, we need "from genesis to tip". Genesis has parent_hash = [0;32].
        // We can call collect_canonical_chain with from_hash = [0;32] (sentinel meaning "from beginning").

        // and genesis's parent IS [0;32], so the walk terminates correctly.

        // If from_hash = [0;32] (genesis parent), it will walk back from tip,
        // push each block hash, until current == [0;32] (genesis's parent).
        // The genesis block IS pushed (it's current before walking to parent).
        // Then parent = [0;32] = from_hash, walk stops. Reverse. Result includes genesis.
        //

        // while current != from_hash { chain.push(current); current = parent }
        // So from_hash is EXCLUDED. If from_hash = [0;32], genesis is INCLUDED
        // because genesis's hash is NOT [0;32], and genesis's PARENT is [0;32].
        // Walk: push genesis, move to parent = [0;32], current == from_hash, stop.

/// Replay events for a single block through ReducerCore (no storage write).
fn replay_block_events<SM, S, C>(
    engine: &mut Engine<SM, S, C>,
    block_hash: &[u8; 32],
) -> Result<(), RecoveryError>
where ...
{
    let stored_events = engine.storage()
        .load_block_events(block_hash)
        .map_err(|e| RecoveryError::Storage(Box::new(e)))?;

    let events: Vec<Event<SM::Cursor, SM::Event>> = stored_events.iter()
        .filter_map(|(cursor_bytes, payload_bytes)| {
            let cursor: SM::Cursor = postcard::from_bytes(cursor_bytes).ok()?;
            let data: SM::Event = engine.codec().decode_event(payload_bytes)?;
            Some(Event { cursor, data })
        })
        .collect();

    engine.replay_events(&events);
    Ok(())
}

/// Fetch gap blocks from source and process them through Engine.
/// Fetches blocks in the height range [from_height, to_height] inclusive.
async fn fetch_gap_blocks<SM, S, ES, C>(
    engine: &mut Engine<SM, S, C>,
    source: &ES,
    from_height: u64,
    to_height: u64,
) -> Result<(), RecoveryError>
where ...
{
    if from_height > to_height {
        return Ok(());
    }

    let mut current_height = from_height;

    loop {
        if current_height > to_height {
            break;
        }

        let blocks = source
            .fetch_blocks(current_height, to_height + 1)  // +1 because fetch_blocks is [from, to)
            .await
            .map_err(|e| RecoveryError::Source(Box::new(e)))?;

        if blocks.is_empty() {
            break; // source has no more blocks in this range
        }

        for block in &blocks {
            engine.process_block(block)
                .map_err(|e| RecoveryError::Storage(Box::new(e)))?;
        }

        // Advance by actual last block height, not by count (Pitfall 5)
        let last_height = blocks.last().unwrap().height;
        current_height = last_height + 1;
    }

    Ok(())
}
```

- Gap blocks go through `process_block` which DOES write to storage (they're new blocks)
- fetch_gap_blocks advances `current_height` by last block's actual height + 1, NOT by block count (per Pitfall 5 in RESEARCH.md)
