- Internal data structure:

```rust
use std::collections::HashMap;
use std::sync::{Arc, Mutex};
use super::Storage;

#[derive(Debug, thiserror::Error)]
pub enum MemoryStorageError {
    #[error("internal lock poisoned")]
    Poisoned,
    #[error("block not found: {0}")]
    BlockNotFound(String),
}

#[derive(Debug, Clone)]
struct StoredBlock {
    parent_hash: [u8; 32],
    height: u64,
    source_id: String,
    events: Vec<(Vec<u8>, Vec<u8>)>,  // (cursor_bytes, payload_bytes)
}

#[derive(Debug, Default)]
struct Inner {
    /// block_hash -> StoredBlock
    blocks: HashMap<[u8; 32], StoredBlock>,
    /// source_id -> canonical tip block_hash
    canonical_tips: HashMap<String, [u8; 32]>,
    /// (source_id, block_hash) -> snapshot payload
    snapshots: HashMap<(String, [u8; 32]), Vec<u8>>,
}

#[derive(Clone)]
pub struct InMemoryStorage {
    inner: Arc<Mutex<Inner>>,
}
```

Implement `Storage` for `InMemoryStorage`:

- `write_block`: Check if block_hash exists in `blocks` map. If yes, return Ok(false). Otherwise, insert StoredBlock, update canonical_tips for the source_id, return Ok(true).
- `get_canonical_tip`: Look up source_id in canonical_tips. Clone the hash if found.
- `get_block_height`: Look up block_hash in blocks map. Return height if found.
- `write_snapshot`: Insert (source_id, block_hash) -> payload into snapshots map.
- `find_nearest_snapshot`: Starting from tip_hash, loop: check if (source_id, current_hash) exists in snapshots. If found, return (current_hash, payload). Otherwise, look up current_hash in blocks to get parent_hash. If parent is all-zeros or block not found, return None. Move to parent.
- `collect_canonical_chain`: Walk backward from to_hash, collecting hashes until from_hash is reached. Reverse the collected list. Returns empty vec if from_hash == to_hash.
- `load_block_events`: Look up block_hash in blocks. Return events clone, or empty vec if not found.

Add `new()` and `Default` impl.
