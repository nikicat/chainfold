Define an ERC20 StateMachine and Codec within the test file (not in lib — this is PoC, not library code):

```rust
// ERC20 Transfer event
#[derive(Debug, Clone)]
struct Transfer { from: [u8; 20], to: [u8; 20], amount: u128 }

// Balance state: HashMap of address -> balance
type Balances = std::collections::HashMap<[u8; 20], u128>;

struct Erc20Machine;
impl StateMachine for Erc20Machine {
    type State = Balances;
    type Event = Transfer;
    type Cursor = EvmCursor;

    fn apply(&self, mut state: Balances, event: &Event<EvmCursor, Transfer>) -> Balances {
        let transfer = &event.data;
        // Debit sender (saturating to handle genesis mints where from=0x0)
        if transfer.from != [0u8; 20] {
            let bal = state.entry(transfer.from).or_insert(0);
            *bal = bal.saturating_sub(transfer.amount);
        }
        // Credit receiver
        *state.entry(transfer.to).or_insert(0) += transfer.amount;
        state
    }
}
```

Define Erc20Codec implementing Codec for Transfer/Balances serialization (use serde_json for simplicity in tests).

Create a MockErc20Source implementing EventSource that yields pre-built blocks of Transfer events. Reuse the mock pattern from existing test files (tests/recovery_tests.rs, tests/reorg_tests.rs).

Write integration tests:

1. **cold_start**: Create engine with InMemoryStorage, process 10 blocks each with 1-2 transfers. Assert store.get() returns expected balances.

2. **restart_recovery**: Process blocks, capture final balance. Create a NEW engine with the SAME Arc<InMemoryStorage>. Call recover(). Assert store.get() on the new engine returns same balance.

3. **reorg_handling**: Process 5 blocks on branch A. Then feed a block at height 4 with different parent (branch B reorg). Assert balance reflects branch B transfers, not branch A.

4. **store_composition**: Create engine, get ReducedStore. Process blocks. Verify store.get() returns updated balance without calling engine.state().

5. **on_change**: Subscribe to store before processing blocks. Spawn a task that processes blocks. In main task, loop on changed().await and collect balance snapshots. Verify transitions.

6. **historical_at**: Process 10 blocks with known transfers. Call reconstruct_at(height=5). Verify balance equals cumulative transfers through block 5 only.
